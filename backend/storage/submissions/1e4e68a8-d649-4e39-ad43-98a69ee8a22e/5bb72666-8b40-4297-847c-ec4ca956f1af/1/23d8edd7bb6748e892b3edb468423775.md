# Spaced Repetition Engine

A dependency-light SM-2 style scheduler for a language-learning application.

## State
- `repetitions`: consecutive successful reviews
- `ease_factor`: interval growth factor, starting at 2.5 and clamped to 1.3
- `interval_days`: days until the next review

## Rules
- Successful first review: 1 day
- Successful second review: 6 days
- Later successful reviews: previous interval × ease factor
- Failed review (`quality < 3`): reset repetitions and interval to 1 day
- Quality is an integer from 0 to 5

## Verification
Run:

```bash
pytest -q test_spaced_repetition.py
```

The tests cover first and second intervals, interval expansion, failed-review reset, ease-factor floor, and invalid input handling.

The review date is injectable so tests are deterministic and do not depend on the machine clock.
